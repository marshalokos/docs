## Prerequisites

- Node.js 18+
- `pnpm` installed globally (`npm install -g pnpm`)

## Get started

<Steps>
  <Step title="Clone the repo">
    ```bash
    git clone https://github.com/marshalokos/explorer.git
    cd explorer
    ```
  </Step>
  <Step title="Install dependencies">
    The project requires `--legacy-peer-deps` due to transitive peer dependency conflicts introduced
    after removing `@bonfida/spl-name-service` (replaced with an inline implementation in `app/utils/spl-name-service.ts`).

    ```bash
    npm install --legacy-peer-deps
    ```
  </Step>
  <Step title="Build">
    ```bash
    npx webpack
    ```
  </Step>
  <Step title="Run">
    Start the Next.js dev server:

    ```bash
    npm run dev
    ```

    Open [http://localhost:3000](http://localhost:3000) in your browser.
  </Step>
</Steps>

<Tip>
  To connect to a custom RPC endpoint, append `?cluster=custom&customUrl=https://your-rpc-url` to any Explorer URL.
</Tip>

## Name service

`.sol` domain resolution is handled via an inline implementation in `app/utils/spl-name-service.ts`.
This replaces the removed `@bonfida/spl-name-service` npm package and implements `getHashedName`,
`getNameAccountKey`, `getNameOwner`, `performReverseLookup`, and `getFilteredProgramAccounts` directly
using `@noble/hashes` and `@solana/web3.js`.
